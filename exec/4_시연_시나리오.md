# 참견도치 - 시연 시나리오

## 1. 시연 개요

### 시연 목적
- 참견도치 플랫폼의 핵심 AI 기능 시연
- 갈등 해결부터 커뮤니티, 화상통화까지 전체 플로우 확인
- 실제 배포 환경에서의 기술적 구현 결과 발표

### 시연 환경
- **배포 URL**: https://i13c209.p.ssafy.io/
- **브라우저**: Chrome 최신 버전 권장
- **해상도**: 1920x1080 (Full HD)
- **준비사항**: 마이크, 카메라 (WebRTC 화상통화용), 2개 디바이스 또는 탭

### 시연 시간 및 플로우
- **총 소요시간**: 약 6-7분
- **핵심 기능별 시간 배분**:
  1. 갈등 카드 생성 → AI 요약: 1분
  2. 토닥토닥 챗봇 대화 확인: 30초분

  4. 5단계 로드맵 확인: 30초
  5. WebRTC 화상채팅 + STT + 감정분석 + AI 중재: 3분
  6. 통화 요약 확인: 1분
