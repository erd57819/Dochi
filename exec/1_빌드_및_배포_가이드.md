## 3. 빌드 과정

### 백엔드 (Spring Boot) 빌드

#### 개발 환경 빌드
```bash
cd SSAFY-DOCHI-BE

# Maven 의존성 설치 및 빌드
mvn clean install

# 테스트 포함 빌드
mvn clean compile test

# 테스트 제외 빌드 (빠른 빌드)
mvn clean install -DskipTests
```

#### 운영 환경 빌드
```bash
# 운영 프로파일로 빌드
mvn clean install -Dspring.profiles.active=prod

# Docker 이미지 빌드
docker build -t dochi-backend:latest .
```

### 프론트엔드 (React + Vite) 빌드

#### 개발 환경
```bash
cd SSAFY-DOCHI-FE

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

#### 운영 환경 빌드
```bash
# 운영용 빌드
npm run build

# 빌드 결과 미리보기
npm run preview

# Docker 이미지 빌드
docker build -t dochi-frontend:latest .
```

### AI 서버 (FastAPI) 빌드

```bash
cd SSAFY-DOCHI-AI

# Python 가상환경 생성 (권장)
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 의존성 설치
pip install -r requirements.txt

# 개발 서버 실행
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# Docker 이미지 빌드
docker build -t dochi-ai:latest .
```

## 4. 배포 과정

### Docker Compose를 이용한 전체 시스템 배포

#### 개발 환경 배포

## 7. 데이터베이스 ERD 및 접속 정보

### 데이터베이스 스키마
```sql
-- 주요 테이블 구조
CREATE DATABASE dochi DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 사용자 테이블
CREATE TABLE users (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    nickname VARCHAR(100) NOT NULL,
    password_hash VARCHAR(255),
    profile_image VARCHAR(500),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 갈등 관련 테이블
CREATE TABLE user_conflicts (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    title VARCHAR(200) NOT NULL,
    content TEXT NOT NULL,
    conflict_type VARCHAR(50),
    intensity INT DEFAULT 1,
    status VARCHAR(20) DEFAULT 'ACTIVE',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 채팅 관련 테이블
CREATE TABLE chat_rooms (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    title VARCHAR(200) NOT NULL,
    session_id VARCHAR(255) UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE TABLE chat_messages (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    chat_room_id BIGINT NOT NULL,
    sender_type VARCHAR(10) NOT NULL, -- 'USER' or 'BOT'
    message TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (chat_room_id) REFERENCES chat_rooms(id)
);
```

### 데이터베이스 접속 정보
```properties
# 개발환경
```

```bash
mysql -h localhost -u dochi_user -p dochi
```
