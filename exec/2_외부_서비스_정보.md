# 참견도치 - 외부 서비스 정보

## 1. 소셜 인증 서비스

### 카카오 로그인 (Kakao OAuth 2.0)

#### 서비스 개요
- **목적**: 사용자 편의성을 위한 소셜 로그인 기능
- **사용 API**: Kakao Developers REST API
- **공식 문서**: https://developers.kakao.com/docs/latest/ko/kakaologin/rest-api

#### 가입 및 설정 과정

1. **카카오 개발자 사이트 가입**
   ```
   URL: https://developers.kakao.com/
   계정: 카카오 계정으로 로그인
   ```

2. **애플리케이션 등록**
   ```
   - 내 애플리케이션 > 애플리케이션 추가하기
   - 앱 이름: 참견도치
   - 회사명: SSAFY
   - 카테고리: 소셜/커뮤니티
   ```

3. **플랫폼 설정**
   ```
   Web 플랫폼 등록:
   - 개발환경: http://localhost:5173
   - 운영환경: https://chamgyeondochi.com
   ```

4. **카카오 로그인 활성화**
   ```
   제품 설정 > 카카오 로그인 > 활성화 설정: ON
   Redirect URI 설정:
   - 개발: http://localhost:5173/auth/kakao/callback
   - 운영: https://chamgyeondochi.com/auth/kakao/callback
   ```

5. **동의항목 설정**
   ```
   필수 동의항목:
   - 닉네임 (profile_nickname)
   - 이메일 (account_email)
   
   선택 동의항목:
   - 프로필 사진 (profile_image)
   ```

#### 발급받는 키 정보
```properties
# 환경변수 설정
KAKAO_CLIENT_ID=your_rest_api_key_here
KAKAO_CLIENT_SECRET=your_client_secret_here  # 선택사항
KAKAO_REDIRECT_URI=http://localhost:5173/auth/kakao/callback

# JavaScript 키 (프론트엔드용)
KAKAO_JAVASCRIPT_KEY=your_javascript_key_here
```

#### 구현 코드 위치
- **백엔드**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/user/service/KakaoOAuthService.java`
- **프론트엔드**: `SSAFY-DOCHI-FE/src/services/kakaoAuthService.js`
- **설정파일**: `SSAFY-DOCHI-FE/src/config/kakaoConfig.js`

## 2. 클라우드 스토리지 서비스

### AWS S3 (Amazon Simple Storage Service)

#### 서비스 개요
- **목적**: 프로필 이미지, 네컷만화 이미지 등 파일 저장
- **사용 기능**: 파일 업로드/다운로드, 정적 웹사이트 호스팅
- **공식 문서**: https://docs.aws.amazon.com/s3/

#### 가입 및 설정 과정

1. **AWS 계정 생성**
   ```
   URL: https://aws.amazon.com/
   계정 타입: 개인 또는 비즈니스
   결제 정보: 신용카드 등록 필요
   ```

2. **S3 버킷 생성**
   ```
   버킷명: dochi-files-production
   리전: ap-northeast-2 (아시아 태평양-서울)
   퍼블릭 액세스: 차단 설정 (보안상 권장)
   ```

3. **IAM 사용자 생성**
   ```
   사용자명: dochi-s3-user
   액세스 유형: 프로그래밍 방식 액세스
   정책: AmazonS3FullAccess 또는 커스텀 정책
   ```

4. **버킷 정책 설정**
   ```json
   {
     "Version": "2012-10-17",
     "Statement": [
       {
         "Sid": "PublicReadGetObject",
         "Effect": "Allow",
         "Principal": "*",
         "Action": "s3:GetObject",
         "Resource": "arn:aws:s3:::dochi-files-production/public/*"
       }
     ]
   }
   ```

#### 발급받는 키 정보
```properties
# AWS 환경변수
AWS_ACCESS_KEY_ID=AKIA...
AWS_SECRET_ACCESS_KEY=your_secret_access_key
AWS_S3_BUCKET_NAME=dochi-files-production
AWS_REGION=ap-northeast-2
```

#### 구현 코드 위치
- **백엔드**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/s3/S3Config.java`
- **서비스**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/user/service/ProfileImageService.java`

## 3. AI 서비스

### GMS (GenAI Model Service) API

#### 서비스 개요
- **목적**: AI 채팅, 이미지 생성, 텍스트 분석
- **기능**: 
  - 챗봇 대화 생성 (Claude, GPT 모델)
  - 네컷만화 이미지 생성
  - 감정 분석 및 갈등 해결책 제안

#### 가입 및 설정 과정

1. **GMS 서비스 가입**
   ```
   - 내부 GMS 플랫폼 접속
   - API 키 발급 신청
   - 사용 목적 및 예상 호출량 명시
   ```

2. **API 엔드포인트 설정**
   ```
   Base URL: https://api.gms.com/v1/
   
   주요 엔드포인트:
   - POST /chat/completions (채팅)
   - POST /images/generations (이미지 생성)
   - POST /analysis/emotion (감정 분석)
   ```

#### 발급받는 키 정보
```properties
# GMS API 설정
GMS_API_KEY=your_gms_api_key_here
GMS_API_URL=https://api.gms.com/v1
GMS_MODEL_CHAT=claude-3-7-sonnet-latest
GMS_MODEL_IMAGE=dall-e-3
```

#### 구현 코드 위치
- **백엔드**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/config/GmsAiClient.java`
- **이미지 생성**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/config/GmsImageClient.java`
- **채팅 서비스**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/chat/service/ChatService.java`

## 4. 이메일 서비스

### Gmail SMTP (이메일 인증)

#### 서비스 개요
- **목적**: 회원가입 시 이메일 인증, 비밀번호 재설정
- **사용 기능**: SMTP를 통한 이메일 발송
- **공식 문서**: https://support.google.com/mail/answer/7126229

#### 설정 과정

1. **Gmail 계정 설정**
   ```
   Gmail 계정: dochi.service@gmail.com
   2단계 인증: 활성화 필수
   ```

2. **앱 비밀번호 생성**
   ```
   Google 계정 관리 > 보안 > 2단계 인증 > 앱 비밀번호
   앱 선택: 메일
   기기 선택: 기타 (사용자 지정 이름)
   이름: DOCHI-Backend
   ```

#### 발급받는 키 정보
```properties
# Gmail SMTP 설정
GMAIL_USERNAME=dochi.service@gmail.com
GMAIL_APP_PASSWORD=your_16_character_app_password

# Spring Boot Mail 설정
spring.mail.host=smtp.gmail.com
spring.mail.port=587
spring.mail.username=${GMAIL_USERNAME}
spring.mail.password=${GMAIL_APP_PASSWORD}
spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true
```

#### 구현 코드 위치
- **이메일 발송**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/user/service/EmailSenderImpl.java`
- **인증 서비스**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/user/service/EmailVerificationService.java`

## 5. 실시간 통신 서비스

### LiveKit (WebRTC 화상통화)

#### 서비스 개요
- **목적**: 실시간 화상통화 및 음성 분석
- **기능**: 
  - P2P 화상통화
  - 음성 데이터 스트리밍
  - 실시간 감정 분석

#### 설정 과정

1. **LiveKit 클라우드 가입**
   ```
   URL: https://cloud.livekit.io/
   계정: GitHub 또는 Google 계정 연동
   ```

2. **프로젝트 생성**
   ```
   프로젝트명: dochi-video-calls
   리전: 서울 (Asia-Pacific)
   ```

3. **API 키 생성**
   ```
   Settings > Keys > Generate New Key
   권한: RoomCreate, RoomJoin, RoomRecord
   ```

#### 발급받는 키 정보
```properties
# LiveKit 설정
LIVEKIT_API_KEY=your_api_key
LIVEKIT_API_SECRET=your_api_secret
LIVEKIT_WS_URL=wss://dochi-xxxxxxxx.livekit.cloud
```

#### 구현 코드 위치
- **백엔드**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/openvidu/service/OpenViduService.java`
- **프론트엔드**: `SSAFY-DOCHI-FE/src/hooks/useOpenVidu.js`
- **화상통화 컴포넌트**: `SSAFY-DOCHI-FE/src/components/videocall/VideoCallRoom.jsx`

## 6. 음성 인식 서비스

### Google Cloud Speech-to-Text

#### 서비스 개요
- **목적**: 화상통화 중 음성을 텍스트로 변환
- **기능**: 실시간 STT, 다국어 지원

#### 설정 과정

1. **Google Cloud Console 가입**
   ```
   URL: https://console.cloud.google.com/
   신규 프로젝트 생성: dochi-speech-project
   ```

2. **Speech-to-Text API 활성화**
   ```
   API 및 서비스 > 라이브러리 > Speech-to-Text API > 사용
   ```

3. **서비스 계정 생성**
   ```
   IAM 및 관리자 > 서비스 계정 > 서비스 계정 만들기
   역할: Cloud Speech Client
   JSON 키 파일 다운로드
   ```

#### 발급받는 키 정보
```properties
# Google Cloud 설정
GOOGLE_CLOUD_PROJECT_ID=dochi-speech-project
GOOGLE_APPLICATION_CREDENTIALS=path/to/service-account-key.json

# 또는 환경변수로 직접 설정
GOOGLE_CLOUD_CREDENTIALS_JSON={"type":"service_account",...}
```

#### 구현 코드 위치
- **백엔드**: `SSAFY-DOCHI-BE/src/main/java/com/ssafy/dochi/stt/controller/STTProxyController.java`
- **AI 서버**: `SSAFY-DOCHI-AI/services/speechService.py`

## 8. 비용 및 제한사항

### 각 서비스별 비용 구조

1. **카카오 로그인**: 무료 (월 호출 제한 있음)
2. **AWS S3**: 사용량 기반 (첫 12개월 5GB 무료)
3. **GMS API**: 토큰 기반 과금 (내부 서비스)
4. **Gmail SMTP**: 무료 (일일 발송 제한 500개)
5. **LiveKit**: 사용 시간 기반 (월 $0.50/GB)
6. **Google Cloud STT**: 사용량 기반 (월 60분 무료)

### 제한사항 및 주의사항

- **카카오 로그인**: 일일 호출 한도 초과 시 제한
- **AWS S3**: 퍼블릭 액세스 설정 시 보안 주의
- **LiveKit**: 동시 접속자 수에 따른 대역폭 비용
- **이메일 발송**: 스팸 정책 준수 필요

---

**보안 주의사항**: 
- 모든 API 키는 환경변수로 관리하고 Git에 커밋하지 않음
- 정기적인 키 로테이션 권장
- 최소 권한 원칙 적용
